# script-to-video-prompts

将剧本转换为专业影视制作文档与生成提示词的完整流水线 Skill。输入短剧剧本/分场剧本/剧情梗概，按需输出：文字分镜脚本 → 手绘导演分镜表预览提示词 → 写实四宫格分镜图提示词 → 模型原生视频提示词。

## 功能

- **文字分镜脚本**：逐镜输出镜号、景别、运镜、情绪/动作、台词、音效、时长，头部含场次/地点/时间/人物。
- **分镜脚本预览提示词**：手绘风格导演分镜表（默认 1-8 镜号），用于结构参考图生成。
- **分镜四宫格提示词**：写实风格四宫格影视剧分镜图提示词（无字幕）。
- **视频提示词**：镜头N 式模型原生提示词，遵循素材编号、主体绑定、四套括号标记语法。
- **按需输出**：默认全量四阶段，也可只输出指定阶段。
- **短剧剧本格式兼容**：识别场次编号、时间地点、人物列表、`△` 动作、`角色名:台词`、`OS`/`VO`、闪回、`【字幕】`、`【空镜】` 等标准标注。

## 安装

将本目录放置到 AI Agent 的 skill 根目录（如 `workspace/.user_skills/`），保持完整目录结构：

```text
workspace/.user_skills/script-to-video-prompts/
```

## 使用

向 Agent 提供剧本文本（或剧本文件），即可触发。可指定输出范围：

| 指令示例 | 输出 |
|---|---|
| 帮我做这个剧本的分镜脚本 | 仅阶段 2 |
| 输出分镜脚本和四宫格提示词 | 阶段 2 + 4 |
| 按流程全量输出 | 阶段 2 → 5 |

## 流水线

```text
剧本输入
  → 阶段2 文字分镜脚本（镜号/景别/运镜/情绪动作/台词/音效/时长）
  → 阶段3 分镜脚本预览提示词（手绘 1-8 镜结构参考图）
  → 阶段4 分镜四宫格提示词（写实、无字幕）
  → 阶段5 视频提示词（镜头N 式模型原生）
```

## 边界

本 Skill 只产出文档与提示词文本，不调用图像/视频生成工具。在豆包环境实际生成时，图像走豆包图像生成工具，视频遵循 `seedance-25`（原文透传）或 `doubao-creative-video`（确认门控）流程，最终提示词以用户确认为准。
