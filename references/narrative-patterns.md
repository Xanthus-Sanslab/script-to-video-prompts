# 叙事模式库

从 `minimax-h3-prompt-skill-T8` 仓库精选 25 个高频叙事/镜头结构合并而成。每个条目给出：触发场景、结构锚点（必守）、镜头/节奏提示。用于阶段 2 分镜设计与阶段 5 视频提示词组织：剧本情节命中某模式时，按锚点组织因果链，不虚构锚点之外的内容。

## A. 舞台表演类

### 对决节奏·静止密战一击定局（stage-calm-dense-delayed-finish）
- **触发**：双主体对峙、静止蓄势、一击定局的对决戏。
- **锚点**：安静建立可读 → 中段交换连续高密 → 决定性干预只有一次 → 假稳定后才出现不可逆结果。
- **镜头**：开场长镜头/中景建立空间与双方；中段快切保持连续；结尾定格不可逆结果，不留多余动作。

### 反差喜剧·越从容越失控（stage-deadpan-chain-failure）
- **触发**：喜剧性连环失误、一本正经地搞砸。
- **锚点**：正式场合 + 沉着主体；负担始终附着主体；至少两次因果连锁；失效可见但主体不慌。
- **镜头**：保持主体表情/姿态克制稳定，失效由道具与环境承担；连锁动作用连续镜头，不切走主体反应。

### 舞台表演·远景起势到倒地复起（stage-performance-fall-rise-arc）
- **触发**：表演/运动场面的完整起落弧。
- **锚点**：开场先证明全身与巨大场地尺度；近景必须晚于动作语言建立；全片只有一次决定性下降；俯拍或地面机位证明落地；结尾连续复起且不回到开场构图。
- **镜头**：远景建立 → 动作语言 → 一次下落（俯拍/地面证明）→ 复起收束。

### 角色登场·细节到全身揭晓（stage-progressive-character-reveal）
- **触发**：新角色/主体首次登场。
- **锚点**：从可识别细节开始；揭晓尺度逐步扩大；角色只做一次代表动作；以全身定格完成身份确认。
- **镜头**：特写细节 → 中景 → 全身；代表动作安排在一次，不做多余表演。

### 惊吓转和解遭遇（stage-startle-to-truce-encounter）
- **触发**：幻想vs科技、隔窗/舱体对视、压迫感遭遇戏（4–15s 非致命）。
- **锚点**：冷静基线 + 可读距离；通过 POV/围封揭示观察者；一次有界升级（警报/防御/骤缩）；空间反转（被观察者闭合不可能距离）；共享轴/匹配速度/正确眼线同框；外部化惊愕（肩/握持/头转/呼吸/注视）；结尾小和解提议 + 可读保持反应。
- **镜头**：4–5 个因果节拍对应 12–15s；决定性接近放在最后四分之一前；每拍一个主相机用途。

### 对话喜剧·双轮停顿无声反应（stage-two-turn-pause-reaction）
- **触发**：双人对话笑点、停顿喜剧。
- **锚点**：开场双人中景建立稳定眼线；只保留一轮第一人说话；两轮之间一次清楚停顿；第二人只说一轮且动作克制；结尾第一人无声反应且不再增加说话轮次。
- **镜头**：双人中景开场，过肩交替；停顿用固定镜头或微推制造间隙。

## B. 揭示类

### 表演让位于环境·近脸到全景连续退镜（reveal-environment-through-performance-pullback）
- **触发**：由人引向环境/场面的揭示。
- **锚点**：开场足够近建立表演者身份；退镜全程保持一条连续表演线；视觉主导权通过相机距离转移而非主体变化；结尾宽景中表演者与响应环境都可读。
- **镜头**：连续退镜/拉远，不切主体；远近关系靠相机距离改变，不做主体变身。

### 第一视角查岗·遮挡失效到摆烂收口（reveal-evidence-through-failed-concealment）
- **触发**：第一人称观察、藏不住证据的喜剧/悬疑。
- **锚点**：一个连续具身第一人称观察者，高度/距离变化来自物理移动；至少两次遮挡尝试各暴露更深矛盾；从物证过渡到持续面部/身体反应；结尾可见行为变化而非第三次揭示。
- **镜头**：手持/主观视角，移动真实；两次遮挡逐层揭穿；收在反应而不是新线索。

### 冲击后揭示·从私密困境到城市尺度真因（reveal-impact-aftermath-at-larger-scale）
- **触发**：小场景受冲击后揭开大因果。
- **锚点**：大事件前亲密受限基线；一个外部力量可见地移位既定载体；运动停止后保持一次冲击后反应；局部后果清楚后才揭示更大原因。
- **镜头**：私密近景 → 冲击动作 → 静止反应 → 大尺度揭示（升格/广角）。

### 程序错位·扫描到实物双确认（reveal-nested-counterpart）
- **触发**：扫描界面与实物的尺度/身份错位。
- **锚点**：主体与程序尺度明显失配；至少三个不同失配证明；扫描先于实物揭晓；实物必须是扫描中的同一对象且两种尺度同框。
- **镜头**：界面特写 → 错位证明连拍 → 实物揭晓 → 同框双确认。

### 地貌变形揭示·局部异常到巨体逼近（reveal-scale-through-environment-deformation）
- **触发**：巨大生物/物体由环境变形引入。
- **锚点**：开场环境变形仍可误认为地形；揭示一个识别特征但保留大部分身体；高/宽视角证明完整几何与环境后果；回到较低视角一次有界逼近。
- **镜头**：地形特写 → 局部特征 → 高角度全貌 → 低机位逼近。

## C. 证明类

### 角色登场·失误后借身体特征破局（prove-competence-through-recoverable-failure）
- **触发**：靠独特身体特征化解失误的能力证明。
- **锚点**：技术任务前建立栖息地/亲密反应/移动；一个可读中间态的技术任务；用身份定义的身体特征作为实用工具；结尾修复或转化对象与克制能力姿势同框。
- **镜头**：环境 → 任务特写 → 破局动作 → 成果与姿态同框。

### 双系统碰撞·同时证明两种规则（prove-dual-system-convergence）
- **触发**：两种材质/运动规则碰撞。
- **锚点**：两系统先独立成立；材质或运动规则明确不同；只发生一次关键汇聚；第三状态同时保留双方证据。
- **镜头**：各系统单独建立 → 一次汇聚 → 混合态同框定格。

### UGC测评·开箱到一口实证（prove-product-through-first-person-test）
- **触发**：测评/开箱/实测类内容。
- **锚点**：开场测评者与未开封产品同框；先完整展示内容再进入细节；只有一个产品专属功能证据；必须完成一次真实使用并保留结果；结尾产品与变化后的反应同框。
- **镜头**：同框开场 → 内容展示 → 单一功能证据 → 真实使用 → 结果反应同框。

## D. 连续/升级类

### 刻意遮断省略·动作升级后以审查卡跳到余波（action-buildup-censored-ellipse-aftermath-reveal）
- **触发**：暴力/冲击场面做省略处理。
- **锚点**：中断前建立两个成人尺度主体与稳定地理；至少三个完整可见动作节拍；中断期间不得描绘/叙述/暗示隐藏动作；回到同一地理只揭示可观察余波状态。
- **镜头**：动作升级连拍 → 审查卡/遮断 → 同地理余波定格。

### 连续前进闯阵·防守闸门升级到高点标志（continuous-forward-gauntlet-elevated-symbolic-finish）
- **触发**：闯关、追逐、闯阵式前进。
- **锚点**：一个主角 + 便携动作工具 + 前进目标轴 + 至少两个重复路线地标；连续前推相机无揭示切；至少三道防守闸门从不同空间方向进入；可减速/位移但不得回到起始状态；最后沿垂直路线放置一个象征物在高点，宽幅证明定格。
- **镜头**：单一前推主相机贯穿；闸门方向错落；终点高角证明定格。

### 未来证据·异常闯入现实（escalate-evidence-into-reality）
- **触发**：预兆/证据画面侵入现实。
- **锚点**：现实基线稳定；同一证据载体至少两次更新；异常先在证据内出现；跨界延迟发生且只有一次克制反应。
- **镜头**：现实 → 证据载体特写更新 → 异常入画 → 延迟跨界 → 一次反应收束。

## E. 材质/尺度/身份类

### 材质引路·空间生长到版式定格（material-carrier-format-collapse）
- **触发**：材质主导的空间生长与版式收尾。
- **锚点**：在稳定主体同一光轴上引入小材质引导；一种连续材质族负责相机引导/颜色积累/空间生长；把同一材质扩展成仍包含原主体与先前调色的环境；一次晚期相机升高把立体场景解成保留主体与材质历史的版式定格。
- **镜头**：材质引导入画 → 连续生长 → 一次上升 → 版式定格。

### 尺度展开·微小材质扩张后原样回收（material-scale-expansion-exact-return-loop）
- **触发**：微物放大成世界再回收。
- **锚点**：扩张前建立紧凑材质锚 + 周围表面 + 可见触发；锚的碎片可见地生成第一个更大结构；收缩前保持一个完整最大尺度世界；反转同一血统与光轴恢复原锚与触发关系。
- **镜头**：同轴推入扩张 → 完整大世界 → 原轴回收闭合。

### 材质字构穿行·同一人物跨物质语义空间（material-typography-world-pass-through）
- **触发**：字体/材质穿越多个语义空间。
- **锚点**：材质字体出现前建立成人主体与固定暗空间轴；每模块一个短原创词 + 一种材质族 + 一种物理行为；用受限孔径/缎带/纸传递压缩前模块而非随机切；所有材质通道汇聚成一个稳定终端肖像 + 可读原创标题。
- **镜头**：暗轴固定 → 逐模块穿行 → 汇聚终端定格。

### 尺度球局·共享球体串联反差挑战（scale-mismatch-sports-token-challenge）
- **触发**：不同尺度主体共享同一物件/目标。
- **锚点**：两种明确不同尺度 + 共享记号 + 同一竞技场固定目标；重复记号控制证明谁拥有动作；一次可读记号轨迹朝向固定目标；结尾可见共享反应状态，只有目标结果直接展示才宣称成功。
- **镜头**：尺度对照建立 → 记号控制连拍 → 一次轨迹 → 共享反应定格。

### 造型轮播·身份锁定跨风格世界（identity-locked-style-world-carousel）
- **触发**：同一角色穿行多风格世界。
- **锚点**：首次切换前建立稳定肖像（脸/身体比例/朝向/相机轴可读）；一个可重复转场门保持面部身份与注册；至少三个材质不同的世界保留相同身份锚点；经同一门回到开场世界与肖像关系。
- **镜头**：稳定肖像 → 同一转场门重复穿越 → 身份锚点贯穿 → 回归闭合。

## F. 场景分支（direct）

### 极简产品广告（direct-seedance-minimalist-product-ad）
- **触发**：4–15s 电商/新品广告，忠实产品形态。
- **锚点**：真实产品图 + 核验 brief；产品专属脊柱（上市揭示/特征触感/色系家族）；动作语言由真实边缘/机制/高光驱动；参考图分开角色（主体身份/材质细节/终版构图）；保持产品本体颜色/表面/比例/接口/包装。
- **镜头**：`镜头N` 证明节拍，无精确时间；一镜一产品主动作 + 一相机运动；`【】` 精确文案、`< >` 产品音、`（）` 音乐按需。

### 音乐字体排版（direct-seedance-music-typography）
- **触发**：MV 片段、音乐字体排版。
- **锚点**：锁定比例/总时长/音乐窗口/歌词所有权/语言/表演者/字体角色；>15s 拆多条 clip 保留主音轨；歌声与节拍映射到表演/场景变化/镜头冲动/字体进入/转场；每镜一个主字体事件，保护眼睛/嘴/对口型。
- **镜头**：`音频1` 绑定音轨；`{歌词}` 表演词、`【可见歌词】` 屏幕字；`镜头N` 事件序，允许节拍词（如"on the snare"）。

### 纸艺讲解（direct-seedance-papercraft-explainer）
- **触发**：科普/教育类纸艺讲解。
- **锚点**：锁主题/受众/核心学习句；选视觉隐喻（弹出式旅程/纸实验室/分层剖面/微型自然剧场/机制板）；只设计有助于讲解的角色；前景/中景/背景/远背景分层，每运动元素有物理纸机制；知识拆因果节拍，15s 约 3–4 个可读变化。
- **镜头**：`镜头N` 只用于新知识状态；锁定/微距/俯视/慢推/侧视视差；`【】` 标签、`{}` 说话、`<>` 触感音、`（）` 音乐。

## 使用规则

- 命中模式时：套用锚点组织分镜因果链与镜头语言，锚点是必守约束，不得省略/重排/弱化。
- 未命中任何模式时：按常规分镜流程处理，不强行套模式。
- 所有模式只复用结构机制，不复用原仓库示例的人/品牌/台词/道具/时间/画面。
