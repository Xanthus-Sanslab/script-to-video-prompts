# 提示词语法规范

写作视频提示词时遵循以下语法。目标是产出模型原生、可审计、可直接粘贴进视频生成模型的文本。

## 1. 素材编号与主体绑定
- 按模态给素材分配连续编号：`图片N`、`视频N`、`音频N`。不同模态各自独立编号。
- 每个素材只承担一个明确职责（身份、场景、动作参考、风格、声音）。
- 模糊主体必须绑定素材：`角色A@图片1`、`场景B@图片2`。
- 不得声明未使用的素材，不得让两个主体共用一个无区分素材。

## 1.1 开头人物介绍块（每个生成单元必写）

每个生成单元的视频提示词正文开头，先写一段"本单元出场人物介绍"，列出本单元实际出场的人物及其当前形态，并预留 `@图片N` 绑定位：

```text
【本单元出场人物】
· 小胖（餐具巨人形态：筷子胸甲+勺子肩甲+吞噬吸尘器）@图片1
· 小胖2（小吃巨人形态：烤串骨架+奶茶血液+美食权杖）@图片2
· 饕餮（小狗形态：圆滚滚、叼着优惠券）@图片3
```

规则：
- 只列本单元镜头里实际出现的人物；路人/背景人群不单列。
- 形态标注随剧本解析阶段的"形态演变时间线"取当前阶段称谓；变身进行中的单元两个形态都列。
- 用户未提供参考图时，`@图片N` 占位保留，方便用户拿到提示词后直接上传参考图绑定；不得删除占位。
- 人物介绍块之后再写镜头1、镜头2…。

## 2. 因果动作链
动作描述按因果链组织，尽量包含：
```
身体/物体部位 → 方向 → 速度 → 力/惯性 → 接触 → 可见后果
```
示例：`角色A 双手推开金属门，门扇加速外旋，撞上墙面后弹回，门框灰尘扬起`。

## 3. 镜头规则
- 一个镜头只有一个主相机行为（固定 / 横移 / 推近 / 环绕 / 手持）。
- 同一镜头内禁止互相冲突的运镜（如既推近又环绕且无切镜）。
- 简单事件：一个自然段落写完整。
- 复杂事件：连续 `镜头1`、`镜头2`、`镜头3`… 块，每块写清构图、主体动作、空间变化、相机、必要声音。
- 禁止在 prompt 内写精确秒数时间戳；镜头时长由因果和空间变化自然决定。

## 4. 四套括号标记
| 标记 | 用途 | 示例 |
|---|---|---|
| `{…}` | 台词/旁白/口播（声音与口型） | `{把伞给我}` |
| `<…>` | 物理/设计音效 | `<门轴摩擦声>` |
| `（…）` | 音乐 | `（轻快钢琴，渐强）` |
| `【…】` | 画面可见文字 | `【新品上市】` |

规则：
- 台词只作为声音/口型内容，不作为画面字幕或花字。
- 未在剧本中出现的台词、音效、音乐、文字一律不写。
- **默认不出现字幕**：`【…】` 画面可见文字仅在剧本明确要求屏幕文字时使用；默认不写字幕、不写片尾字幕条，画面不渲染任何文字。
- **默认不出现背景音乐**：`（…）` 音乐标记默认不使用；只保留 `<…>` 物理/环境音效。用户明确要求配乐时才使用 `（…）`。
- 每个生成单元提示词末尾统一补一句："画面中不出现字幕，不出现背景音乐。"（用户明确要求字幕/音乐时删除该句）

## 5. 主体稳定性与独立单元自包含
- 每段/每个镜头都复述核心外观锚点（发型、服装主色、轮廓），防止漂移。
- 参考素材存在时，在 prompt 中保持 `角色A@图片1` 的绑定关系。
- 不换脸、不改服装主色、不改变体型。

### 5.1 独立单元自包含规则（每个生成单元必满足）

每个生成单元会被单独喂给视频模型，**不能假设模型记得前序单元的任何信息**。因此每个单元必须自包含：

1. **人物介绍块完整**：单元开头【本单元出场人物】里每个角色带当前形态 + 2–3 个外观锚点 + `@图片N` 占位（见 1.1）。
2. **场景锚点完整**：人物介绍块后紧跟一行【场景】，用一句话交代本单元发生的地点、时间、光线、空间状态（如"小吃街中央广场·白天·热闹街市·两个光柱刚落下"），不依赖前文。
3. **镜头内首次出现复述锚点**：每个镜头正文里，人物/物体首次出现时不只写名字，要带上核心识别物或形态关键词（如"穿围裙的摊主E""金色光晕中的学生P"），后续同镜头可简称。
4. **道具与特效自解释**：本单元涉及的关键道具（卡片、吸尘器、权杖、优惠券）在首次出现时带一句外观描述，不假设模型知道它长什么样。

用户只拿单个单元去生成时，该单元文本本身必须足以让模型正确还原主体、场景和关键道具。

## 6. 禁项
- 禁止 H3 / 内部字段名、`[Shot N]`、`(S1)`、时间轴对齐语法。
- 禁止精确秒数时间戳。
- 禁止把工具参数（时长、比例、模型）写进 prompt 文本。
- 禁止编造品牌、台词、人物、事件。
- 禁止默认输出字幕/片尾字幕条（剧本明确要求可见文字时除外）。
- 禁止默认指定背景音乐（用户明确要求配乐时除外）。

## 7. 画面描写密度规范（写镜头正文时遵循）

视频提示词正文是写给模型的画面指令，不是分镜表复述。按以下密度原则写：

### 要写的
- **动作链**：部位 → 方向 → 速度 → 接触 → 可见后果（如"烤串竹签拼成胸腔骨架，琥珀色奶茶沿血管状纹路流淌"）。
- **镜头运动**：每镜带具体运动方向（如"沿身体侧面缓慢上移""从脚边升起"），不只写景别标签。
- **道具位置**：关键道具在哪只手、顶端有什么（如"右手持吸尘器造型武器，左手举美食权杖，权杖顶端插着糖葫芦"）。
- **动作分解**：关键动作拆成 2–3 个可见步骤（如"五指缓慢张开又合拢，餐具关节轻微摩擦"）。
- **材质质感**：必要的材质词（竹签、琥珀色奶茶、浅黄煎饼面皮）帮助模型还原视觉。

### 不要写的
- **群演表情特写**：不写"所有人仰头张嘴""观众惊讶"——易触发夸张渲染，氛围交给环境音。
- **夸张尺度比喻**：不写"身高五米、人群巴掌大"——"巨人"本身已传达尺度。
- **心理描写**：不写"他内心震撼""得意地想"——全部状态用可见动作/表情/环境传达。
- **环境过度填充**：不堆砌"光粒漂浮、尘屑震起"——一句环境锚点即可。
- **重复复述外观**：主体在单元开头或首次出场时定义一次，后续镜头不重复外观描述。

### 密度原则
- 约束句（无字幕无音乐等）比动作设计短。
- 重大场面（变身/吃播/降临）把笔墨给动作链本身，氛围留给模型发挥。
- 简单反应镜写 1 个动作点即可；复杂场面写 3–4 个动作点。
