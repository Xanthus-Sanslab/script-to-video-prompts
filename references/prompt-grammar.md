# 提示词语法规范

写作视频提示词时遵循以下语法。目标是产出模型原生、可审计、可直接粘贴进视频生成模型的文本。

## 1. 素材编号与主体绑定
- 按模态给素材分配连续编号：`图片N`、`视频N`、`音频N`。不同模态各自独立编号。
- 每个素材只承担一个明确职责（身份、场景、动作参考、风格、声音）。
- 模糊主体必须绑定素材：`角色A@图片1`、`场景B@图片2`。
- 不得声明未使用的素材，不得让两个主体共用一个无区分素材。

## 2. 因果动作链
动作描述按因果链组织，尽量包含：
```
身体/物体部位 → 方向 → 速度 → 力/惯性 → 接触 → 可见后果
```
示例：`角色A 双手推开金属门，门扇加速外旋，撞上墙面后弹回，门框灰尘扬起`。

## 3. 镜头规则
- 一个镜头只有一个主相机行为（固定 / 横移 / 推近 / 环绕 / 手持）。
- 同一镜头内禁止互相冲突的运镜（如既推近又环绕且无切镜）。
- 简单事件：一个自然段落写完整。
- 复杂事件：连续 `镜头1`、`镜头2`、`镜头3`… 块，每块写清构图、主体动作、空间变化、相机、必要声音。
- 禁止在 prompt 内写精确秒数时间戳；镜头时长由因果和空间变化自然决定。

## 4. 四套括号标记
| 标记 | 用途 | 示例 |
|---|---|---|
| `{…}` | 台词/旁白/口播（声音与口型） | `{把伞给我}` |
| `<…>` | 物理/设计音效 | `<门轴摩擦声>` |
| `（…）` | 音乐 | `（轻快钢琴，渐强）` |
| `【…】` | 画面可见文字 | `【新品上市】` |

规则：
- 台词只作为声音/口型内容，不作为画面字幕或花字。
- 未在剧本中出现的台词、音效、音乐、文字一律不写。
- **默认不出现字幕**：`【…】` 画面可见文字仅在剧本明确要求屏幕文字时使用；默认不写字幕、不写片尾字幕条，画面不渲染任何文字。
- **默认不出现背景音乐**：`（…）` 音乐标记默认不使用；只保留 `<…>` 物理/环境音效。用户明确要求配乐时才使用 `（…）`。
- 每个生成单元提示词末尾统一补一句："画面中不出现字幕，不出现背景音乐。"（用户明确要求字幕/音乐时删除该句）

## 5. 主体稳定性
- 每段/每个镜头都复述核心外观锚点（发型、服装主色、轮廓），防止漂移。
- 参考素材存在时，在 prompt 中保持 `角色A@图片1` 的绑定关系。
- 不换脸、不改服装主色、不改变体型。

## 6. 禁项
- 禁止 H3 / 内部字段名、`[Shot N]`、`(S1)`、时间轴对齐语法。
- 禁止精确秒数时间戳。
- 禁止把工具参数（时长、比例、模型）写进 prompt 文本。
- 禁止编造品牌、台词、人物、事件。
- 禁止默认输出字幕/片尾字幕条（剧本明确要求可见文字时除外）。
- 禁止默认指定背景音乐（用户明确要求配乐时除外）。
