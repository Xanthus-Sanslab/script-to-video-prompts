# 剧本解析清单

把剧本文本读入后，按以下维度提取结构化信息。只提取剧本中实际存在的内容，缺失项标记"未提供"并记录为待追问项。

## 0. 短剧剧本格式要素识别

识别并保留剧本原文的格式标注，分镜脚本阶段必须沿用：

| 格式要素 | 写法 | 解析动作 |
|---|---|---|
| 场次编号 | `第X集` / `X-X` | 记录场次号，用于分镜头部"场次" |
| 时间地点 | `内 酒店房间 夜/雨` | 拆分时间（日/夜/雨）与地点，标注内/外 |
| 人物列表 | `人物：林夏、周砚、服务员若干` | 按重要性排序，保留全名 |
| 动作行 | `△ 林夏站在窗前…` | 转写为分镜的"情绪/动作" |
| 台词 | `周砚(压低声音)：…` | 保留角色名与语气提示 |
| 内心独白 | `角色名(OS):内容` | 分镜台词标 `角色名(OS)：…` |
| 画外音 | `角色名VO：…` / `服务员VO：…` | 分镜台词标 `角色名VO：…` |
| 闪回 | `闪回` … `闪回结束` | 独立镜头组，可标 `【闪回】` 段落 |
| 字幕 | `【字幕:内容】` | 记录为可见文字（阶段 5 用 `【…】`） |
| 空镜 | `【空镜:场景描述】` | 转为独立空镜镜头 |

## 1. 角色
| 字段 | 说明 |
|---|---|
| 名字/称呼 | 剧本中的稳定称呼（全名统一），用于 `角色A` 标签 |
| 外观锚点 | 发型、脸型、体型、服装主色、标志性配饰，取 2–3 个 |
| 关系 | 角色间关系（对手/同伴/亲属），影响动作因果 |
| 情绪基线 | 出场默认情绪，用于镜头表演描述 |

### 1.1 人物形态演变时间线（剧本解析后必做）

剧本分析完成后，必须基于剧本内容梳理每个角色的**形态/身份变化节点**，写成时间线，作为后续分镜脚本与视频提示词称谓一致性的依据：

```text
角色：原名
  镜号 X 之前 → 形态A（称谓：角色名）
  镜号 X → 触发事件（变身/换装/受伤/衰老/克隆/合体…）
  镜号 X 之后 → 形态B（称谓：角色名（形态B））
```

规则：
- 形态变化节点由剧本证据触发（变身描写、换装、克隆分身、受伤、年龄变化、身份揭露），不得臆造。
- 分镜脚本与视频提示词中，**称谓必须跟随当前形态**：变身完成后的镜头不得再使用变身前的旧称谓；恢复原形后同理切回。
- 同一角色的不同形态视为同一人物的不同状态，`@图片N` 绑定时以当前形态为准；形态变化跨单元时在人物介绍块里显式标注。
- 该检查在剧本解析后、写分镜前完成；输出文档时在流水线说明里附一份形态演变时间线摘要。

## 2. 场景与环境
| 字段 | 说明 |
|---|---|
| 地点 | 具体空间（诊室、天台、列车内…） |
| 环境状态 | 时间、天气、空间布局（前景/背景、障碍物） |
| 屏幕地理 | 主体在画面中的位置关系，先定地理再写运镜 |

## 3. 事件链
按 `setup → trigger → visible change → payoff` 拆解：
- **setup**：初始画面状态
- **trigger**：触发事件
- **visible change**：可被镜头看见的变化
- **payoff**：结果状态与收束

每个主要变化必须有明确的主体动作或回应；同一镜头避免塞入多个独立事件。

## 4. 台词与旁白
- 逐句提取原文与说话者，保留语气提示 `()`、`OS`、`VO` 标注。
- **不得补写剧本不存在的台词**。
- 阶段 5 进入视频提示词时用 `{…}` 包裹，作声音/口型内容。

## 5. 声音与音乐
- 只收录剧本明确要求的拟音与音乐情绪。
- 剧本未提及则分镜音效写"无"或按场景证据推断并标注"推断"。

## 6. 镜头语言
- 提取剧本已有的运镜/景别描述；未提时由 AI 按"一个镜头一个主相机"分配。
- 情绪/动作描述须画面化，避免小说化语言。

## 7. 参考素材
- 标记剧本涉及、可能需要参考图的实体（主角、场景、产品、IP）。
- 参考图作为独立输入，不把图片内容写进 prompt；仅在视频提示词中用 `角色A@图片1` 绑定。

## 8. 待追问清单
剧本未提供且生成必需的信息，集中列出一次问清：
- 目标总时长（秒）与每镜时长偏好
- 比例（16:9 / 4:3 / 1:1 / 3:4 / 9:16 / 21:9）
- 目标模型（seedance_2.0 / 2.5 等）与时长上限
- 是否输出全量四阶段或指定阶段
- 是否有参考图/素材及其用途
- 口播/字幕语言
