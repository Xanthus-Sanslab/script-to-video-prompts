# 输出模板与审计

## 阶段 2：文字分镜脚本模板

```text
场次：<编号>
地点：<场景>
时间：<日/夜 + 内/外>
人物：<按重要性排序>

镜号：<N>
景别：<景别/主体>
运镜：<主相机行为>
情绪/动作：<画面描述>
台词：<角色名：台词 | 无>
音效：<环境底噪、拟音、氛围音>
时长：<Ns>
```

（逐镜重复，镜号连续。字段细则见 `storyboard-format.md`。）

## 阶段 3：分镜脚本预览提示词模板

输出固定提示词，仅替换镜号范围（默认 1-8）：

```text
根据分镜表脚本，制作一张手绘风格的导演分镜表，只生成前八个镜号的分镜表，忽略其他镜号，从左至右依次包含镜号、分镜图、景别、运镜、情绪/动作、台词、音效、时长，不需要刻画细节，只用做结构参考。
```

- 镜号超过 8 时按 1-8 截取；用户指定范围时按用户范围。
- 交付时前标注"分镜脚本预览提示词输出"。

## 阶段 4：分镜四宫格提示词模板

输出固定提示词：

```text
根据分镜脚本帮我生成一张四宫格影视剧分镜图，要求人物在场景中的位置和空间关系合理，写实风格，不要出现字幕。
```

- 四格默认取开端、转折、高潮、收束四个关键镜头；用户指定镜头时按用户指定。
- 交付时前标注"分镜四宫格提示词输出"。

## 阶段 5：视频提示词模板

### 前置确认（强制）

输出视频提示词前，先确认模型输出上限并向用户确认：

- 上限 30 秒：seedance_2.5 等支持 30 秒的模型，单元时长 5–30 秒。
- 上限 15 秒：seedance_2.0 / 2.0_fast 等，单元时长 4–15 秒。

### 规划卡（内部填写）

```text
Target:     [新生成/参考/编辑/延长/补帧/组合], [模型上限 30s 或 15s], [比例]
Model cap:  [30s | 15s]（已与用户确认）
Units:      [按场次/镜头组拆分，每单元时长 ≤ 上限]
Subjects:   [稳定标签 + 2–3 身份锚点]
Assets:     [图片N / 视频N / 音频N → 单一职责]
Event chain: [setup → trigger → visible change → payoff]
Primary camera: [每镜头一个主相机]
Sound/text: [仅剧本已有或证据支持的层]
```

### 单元拆分规则

- 每个生成单元总时长 ≤ 模型上限（30s 或 15s）。
- 场次超过上限时拆分为多个连续单元，编号"单元1/单元2/…"并在交付中标注各单元时长。
- 单元内镜头时长合计 ≤ 上限；超出时重新分配各镜时长或切分镜头。
- 拆分以因果断点优先（镜头间有明显承接边界处拆分），避免在动作中间切断。

### 多镜头输出骨架

```text
镜头1：[构图 + 主体动作 + 空间变化 + 主相机 + 必要声音]
镜头2：[因果承接 + 新可见信息 + 连贯相机 + 必要声音]
镜头3：[结果/收束 + 可读停留 + 必要声音]
约束：[仅身份、几何、媒介、接触、连续性或文字保护]
```

- 每个分镜镜头对应一个 `镜头N` 块，因果承接。
- 台词 `{…}`、音效 `<…>`、音乐 `（…）`、可见文字 `【…】`。
- 禁止精确秒数时间戳；分镜时长不写入。
- 单场单事件可合并为单段式（见 `prompt-grammar.md`）。

## 最终审计清单

输出前逐项核对：

1. 分镜脚本：镜号连续、景别/运镜/情绪动作/台词/音效/时长七字段齐全，时长合计与总时长一致（±1s）。
2. 分镜脚本：台词、音效均有剧本依据，未虚构；称谓统一。
3. 预览提示词：明确手绘风格、1-8 镜、结构参考、不刻画细节。
4. 四宫格提示词：明确写实、空间关系合理、无字幕。
5. 视频提示词：镜头连续、主体与素材标签双向可解析、单镜头无矛盾相机、台词有据、无时间戳/H3 字段/工具参数混入。
6. 单元拆分：每生成单元时长 ≤ 已确认的模型上限（30s 或 15s）；单元编号与拆分断点合理。
7. 按需输出范围与用户要求一致（默认全量）；阶段 5 在模型上限确认前不得输出。

任一项不通过则重写对应部分后再交付。
