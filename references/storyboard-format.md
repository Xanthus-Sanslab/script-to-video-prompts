# 文字分镜脚本格式规范

## 头部四行

```text
场次：<剧本场次编号，如 1-1>
地点：<具体场景，可含医院/公司等限定>
时间：<日/夜/晨/傍晚 + 内/外，特征可写雨等>
人物：<按重要性排序，全名统一>
```

## 逐镜七字段

```text
镜号：<从 1 连续编号>
景别：<景别类型 + 主体/用途>
运镜：<相机行为，一个镜头一个主相机>
情绪/动作：<画面内容描述，含人物动作与氛围>
台词：<角色名：台词，或 无>
音效：<环境底噪、拟音、氛围音；未指定写无>
时长：<秒数，如 2s>
```

### 景别取值参考
全景/建立镜头、中景、近景、特写、过肩镜头、俯拍、仰拍、主观镜头、插入镜头。
写法示例：`全景/建立镜头`、`近景/女医生`、`过肩镜头/患者看医生`。

### 运镜取值参考
固定镜头、轻微前推、后拉、横移、跟拍、环绕、手持轻微晃动、切入、推近、降机位。
写法示例：`固定镜头，轻微前推`、`固定，略低机位`、`切入，稳定构图`。

### 情绪/动作写法
- 先写镜头功能（交代环境/建立关系/制造氛围），再写人物动作细节。
- 避免小说化语言，使用可拍摄的画面化描述。
- 可写人物心理氛围（如"制造不安感"），但以可见动作/表情承载。

### 台词写法
- 只使用剧本已有台词，格式 `角色名：台词`。
- 无台词写 `无`，不虚构。
- 剧本中的 OS（内心独白）、VO（画外音）保留标注：`女医生(OS)：…`。

### 音效写法
- 分层列出：环境底噪（如"门诊室环境底噪"）、动作拟音（"纸张翻动"）、氛围音（"低频氛围音起"）、人声（"远处候诊叫号声"）。
- 剧本未指定时按场景证据推断，不虚构品牌或特异声音。

### 时长规则
- 每镜 1–5 秒，按镜头信息密度分配（建立镜头 2s、对话近景 3–4s、动作镜头 2–3s）。
- 全片各镜时长合计与目标总时长一致（误差 ±1s）。
- 时长是本阶段外部文档字段，禁止写入阶段 5 的视频提示词内部。
